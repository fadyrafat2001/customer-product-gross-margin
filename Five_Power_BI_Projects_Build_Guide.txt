# Customer and product gross margin

Status: synthetic source assets only, no executed Power BI report. Prepared with assistant support. Not prior independent work.

## Business question
Which products and customers contribute gross profit after discounts?

## Data and model
60 unique invoice lines, synthetic positive sales only. COGS is assigned per sold line and matches sold units. Discounts are amounts, not percentages to be summed.

## Relationships
DimMonth, DimCustomer and DimProduct each filter the corresponding FactSales column, active 1:* single direction. Three relationships.

## Import and implementation
Open the accompanying XLSX in Power BI Desktop using Get data > Excel > Transform Data, or use Queries.pq with the WorkbookPath parameter. Each commented query block is a separate query, not one script to paste wholesale. Load only the named data sheets. Set explicit data types; parse dates with en-US where applicable. Remove auto-created relationships, then create the specified ones. Add DAX measures individually and format ratios as percentages, money as EGP. Hide unused fact columns and use dimension fields for filters.

## Report pages
Overview: net sales, gross profit and margin cards; product/customer profit bars. Detail: customer-product matrix and invoice drill-through. QA: discounts between 0 and gross, no missing COGS, totals reconcile and margin grand total uses totals ratio.

## Tests
Expected_Results.json was independently calculated from these inputs in Python. M/DAX have NOT been executed. Match whole-dataset results and relevant filters before calling the report complete. Check each dimension key is unique and non-null; each fact key matches a dimension; required numeric inputs have no nulls or errors. No silent replacement of missing values with zero. Test slicers, clear-all, cross-highlighting, tooltip and drill-through, and confirm totals do not duplicate after relationships. Save PBIX and capture report + Model view; record Desktop version, refresh date and test results.

## Limits
Gross profit is not operating or net profit. No returns, tax, freight, customer acquisition cost, overhead allocation or currency conversion. Do not average row gross-margin percentages; ratio of totals is required. All customer IDs are fictional.

## Field dictionary
Invoice_Line is a unique fictional invoice line. Month is period YYYY-MM; Customer and Product are dimension keys. Units is sold quantity. Gross_Sales_EGP is pre-discount revenue, Discount_EGP is the monetary reduction, and COGS_EGP is assigned cost for sold units. All amounts are EGP, not per-unit rates. No customer identities are real.

// UNEXECUTED M SOURCE. Create text parameter WorkbookPath with full local XLSX path.
// Create this function as fxSheet; invoke it once per data sheet below.
(sheetName as text) as table =>
let
    Source = Excel.Workbook(File.Contents(WorkbookPath), null, true),
    Data = Source{[Item=sheetName, Kind="Sheet"]}[Data],
    Headers = Table.PromoteHeaders(Data, [PromoteAllScalars=true])
in
    Headers

// Separate query named FactSales:
let
    Source = fxSheet("FactSales"),
    Typed = Table.TransformColumnTypes(Source, {{"Invoice_Line", type text}, {"Month", type text}, {"Customer", type text}, {"Product", type text}, {"Units", type number}, {"Gross_Sales_EGP", type number}, {"Discount_EGP", type number}, {"COGS_EGP", type number}}, "en-US")
in
    Typed

// Separate query named DimMonth:
let
    Source = fxSheet("DimMonth"),
    Typed = Table.TransformColumnTypes(Source, {{"Month", type text}}, "en-US")
in
    Typed

// Separate query named DimCustomer:
let
    Source = fxSheet("DimCustomer"),
    Typed = Table.TransformColumnTypes(Source, {{"Customer", type text}}, "en-US")
in
    Typed

// Separate query named DimProduct:
let
    Source = fxSheet("DimProduct"),
    Typed = Table.TransformColumnTypes(Source, {{"Product", type text}}, "en-US")
in
    Typed



EXACT UNEXECUTED DAX SOURCE
// UNEXECUTED DAX. Create each definition as a separate measure.

Gross Sales EGP = SUM(FactSales[Gross_Sales_EGP])

Discount EGP = SUM(FactSales[Discount_EGP])

Net Sales EGP = [Gross Sales EGP] - [Discount EGP]

COGS EGP = SUM(FactSales[COGS_EGP])

Gross Profit EGP = [Net Sales EGP] - [COGS EGP]

Gross Margin Pct = DIVIDE([Gross Profit EGP], [Net Sales EGP])

Discount Rate = DIVIDE([Discount EGP], [Gross Sales EGP])

Units Sold = SUM(FactSales[Units])
